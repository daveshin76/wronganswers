수능 영어 독해 오답은 무작위가 아니야. 8가지 유형으로 완전히 분류되고, 각 유형마다 지문에 명확한 신호가 있어. 듣기 종료 후 독해 가용 시간 42분을 기준으로 각 문항의 목표 시간을 설정했어.

실전 4단계 소거 프로토콜
ELIMINATION PROTOCOL v2 — 42분 내 선지를 만날 때마다 이 순서로 실행
1
소재 검증 — "지문에 있는 이야기인가?"
선지의 핵심 명사가 지문에 등장하는지 확인. 없으면 즉시 소거. Recognition Bias 주의 — 지문 단어가 있어도 의미가 바뀌었으면 2단계로. Relevance Theory 적용: 선지가 지문 맥락에서 최소 처리 노력으로 최대 인지 효과를 내는지 확인.
① Intrusion② Subset③ Scope Creep
2
방향 검증 — "지문의 논지 방향(Slot B)과 같은가?"
소재가 맞아도 방향(극성)이 같은지 확인. Appraisal Engagement 적용: 지문의 Disclaim(However/But) + Proclaim(clearly/must) 이후 = Slot B. 선지가 Slot B 방향인지 대조.
④ Antonym⑤ C-E Reversal
3
위치 검증 — "지문의 핵심 자리(Nucleus/Slot B)에서 온 내용인가?"
소재·방향이 맞아도 Slot A(Attribute/통념 구간) 내용이면 오답. Appraisal Engagement: Attribute(According to / Many argue) 구간 = Slot A. Proclaim(clearly/must) 구간 = Slot B = 정답 위치.
⑥ True-but-Irrelevant⑦ Misattribution
4
프레임 검증 — "이중부정·프레임 전환이 없는가?" ★NEW
소재·방향·위치가 모두 맞아 보여도 이중부정·반의어 치환·긍정↔부정 프레임 전환으로 의미가 뒤집혔으면 소거. Framing Effect(Kahneman): "not A"를 "B(반의어)"로 재프레이밍. 최종 명제 방향(참/거짓)만 비교.
⑧ Framing Effect
42분 압박 상황에서: 4단계 전부 실행이 어려우면 ① 소재 → ② 방향 순서로만 해도 오답 80% 소거. ③④단계는 2개로 좁혀진 후 적용.
Group 1 — 소재 문제 유형 (①②③)
1
Intrusion 침입형
지문에 없는 소재·개념을 끌어온 선지
선지의 핵심 소재가 지문 어디에도 등장하지 않는 유형. 가장 흔하고 소거가 가장 빠름.
이론: Van Dijk 거시구조 (지문 소재 목록) · Bernstein 내부 논리 (지문 외부 맥락 금지)
지문 내 신호 (Signal)
선지 소재가 지문에 없음. 종종 지문 주제와 인접한 연상 소재를 쓰는 함정이 동반됨.
예: 회의 지문 → "평가회" / 기후 지문 → "에너지 효율" / 기억 지문 → "신경가소성 훈련법"
소거 동작 (Action)
선지를 읽으며 핵심 명사를 지문에서 찾는다. 없으면 즉시 소거 (42분 기준: 3초 이내).
Bernstein 폐쇄계 원칙: 지문 외부의 배경지식이 선지로 침입한 것 = 항상 오답.
실전 예시
빈칸 추론 — Intrusion 함정
지문: 전문가 예측이 우연보다 별로 낫지 않다 (행동경제학 주제).
오답: "collaborative decision-making improves accuracy" — 협업 의사결정은 지문에 없음. 행동경제학 소재와 인접한 Intrusion.
→ "collaborative"를 지문에서 검색 → 없음 → 즉시 소거 (3초).
24번 제목 추론 — Recognition Bias 동반 Intrusion
지문: 알고리즘이 다양한 분야에서 복잡한 의사결정을 수행.
오답: "How Algorithms Decrease Human Creativity" — "creativity" 지문에 없음. "algorithms"는 지문 단어지만 "creativity"는 연상 Intrusion.
→ "creativity" 지문 검색 → 없음 → 소거. Recognition Bias: "algorithm" 재활용으로 친숙하게 보임.
2
Subset 협소형
지문의 예시 중 일부만 커버하는 선지 — 범위가 너무 좁음
지문에는 있는 내용이지만 지문 전체가 아닌 예시 하나에만 해당하는 선지. 지붕 테스트로 판별.
이론: Van Dijk 거시규칙 일반화 단계 실패 · RST Satellite → Nucleus 혼동
지문 내 신호 (Signal)
지문에 예시가 여러 개 나열됨. 선지가 그 중 하나만 다룸.
RST 관점: 선지가 Nucleus가 아닌 Satellite(예시) 내용.
소거 동작 (Action)
지붕 테스트: "이 선지가 지문의 다른 예시들도 포괄하는가?" — 포괄 못하면 소거.
Van Dijk 거시규칙: 여러 예시를 아우르는 상위 일반화 개념 = 정답.
실전 예시
24번 제목 — Subset 함정
지문: 알고리즘이 은행·비행·공장·자동차 분야에서 사용됨.
오답: "Dangers of Online Banking Algorithms" — 은행 예시 하나만. 비행·공장·자동차 포괄 불가.
→ 지붕 테스트: "bank"만 다룸 → 다른 예시 포괄 불가 → 소거.
빈칸 추론 — Subset 함정
지문: "What distinguishes the best forecasters is not domain knowledge but [빈칸]"
오답: "updating beliefs in response to evidence" — 빈칸 뒤 설명에 있는 여러 속성 중 하나만. 지붕 못 됨.
→ 지붕 테스트: "multiple frameworks + update + calibrated uncertainty" 전체 포괄 불가 → 소거.
3
Scope Creep 과잉 일반화형
지문보다 범위가 지나치게 넓은 선지 — Subset의 반대
지문 내용을 과도하게 넓은 상위 개념으로 일반화한 선지. 특히 "always / never / all" 극단어가 동반.
이론: Van Dijk 거시규칙 과잉 적용 · 학술 헤징 전략 위반 (지문의 Hedge 제거)
지문 내 신호 (Signal)
지문이 구체적·제한적 주장을 하는데 선지가 훨씬 넓은 일반 명제.
헤징 언어 제거 패턴: 지문 "tend to reduce" → 선지 "always reduces". 지문의 Hedge가 선지에서 사라짐 = Scope Creep 신호.
소거 동작 (Action)
"지문이 이 넓은 주장을 직접 했는가?" — No이면 소거.
극단어 체크: "always / never / all / only / completely" → 지문에서 그 강도인지 확인.
실전 예시
23번 주제 — Scope Creep 함정
지문: 아이들이 자발적 활동으로 수학 개념을 형성한다.
오답: "importance of early childhood education" — 유아교육 전반으로 비약. 지문은 자발적 수학 탐구만 다룸.
→ "지문이 교육 시스템의 중요성을 직접 주장했나?" → No → 소거.
빈칸 추론 — Hedge 제거 Scope Creep
지문: "experts tend to perform only marginally better than chance"
오답: "experts are completely unreliable in prediction" — "tend to marginally" → "completely unreliable"로 극단화. Hedge 제거.
→ 지문 강도: "tend to / marginally" vs 선지 강도: "completely" → 불일치 → 소거.
⚠
Subset vs Scope Creep: Subset = 지문보다 좁음 ("은행 예시만") / Scope Creep = 지문보다 넓음 ("유아교육 전반"). 소거 질문이 다름: Subset → "다른 예시도 포괄?" / Scope Creep → "지문이 이 넓은 주장을 직접 했나?"
Group 2 — 방향 문제 유형 (④⑤)
4
Antonym 역방향형
지문의 논지·방향·극성과 정반대인 선지
소재는 맞지만 지문 논지 방향과 정반대. Recognition Bias와 결합 시 가장 위험.
이론: Kintsch Slot A vs Slot B 구분 · Appraisal Theory Disclaim/Proclaim · Bakhtin 다성성 (통념 목소리 ≠ 필자 목소리)
Appraisal Theory 적용 — 통념 vs 필자 목소리 분리
Attribute(타인 목소리) 구간: "According to X / Many argue / It is commonly believed" → Slot A = 오답 지역
Disclaim(반박) + Proclaim(선언) 구간: "However / Yet + Clearly / must / in fact" → Slot B = 정답 방향

Antonym 오답 = Attribute 구간(통념·Slot A)을 필자 주장처럼 포장한 선지.
소거 동작 (Action)
Slot B 핵심 방향(Disclaim + Proclaim 이후) 먼저 확인 → 선지 방향과 비교.
Recognition Bias 체크: 지문 단어 있으면 "지문에서와 같은 방향으로 쓰였는가?" 추가 확인.
실전 예시
21번 함축 의미 — Antonym + Recognition Bias
지문: 잔을 내려놓아라 = 스트레스 해소(Slot B 방향).
오답: "pour more water into the glass" = 스트레스 추가. Slot A 방향.
→ 은유 매핑(Blending Theory): down(내려놓기=해소) vs more(추가=악화) → 방향 반대 → 소거.
32번 빈칸 — Recognition Bias + Antonym 이중 함정 ★
지문: 쌀 가격↑ → 쌀 소비↑(기펜재). 가격↓ 시나리오: "고기에 더 씀".
오답: "order more meat" — "meat"는 지문 단어지만 가격↓ 시나리오(Slot A 조건) 내용. 빈칸은 가격↑ 시나리오(Slot B).
→ "meat" 지문에 있음 → Recognition Bias 발동 → 그러나 반대 조건의 내용 → Antonym → 소거.
5
Cause-Effect Reversal 인과 역전형
원인과 결과의 자리를 바꾼 선지
지문: "A → B" / 선지: "B → A". 방향(극성)이 반대인 Antonym과 달리, 인과의 주어·목적어가 swap됨.
이론: Halliday·Hoey 인과 결속성 · Kintsch 명제 극성 구조 · Event Segmentation (원인 Event → 결과 Event 순서)
Event Segmentation 적용 — 원인·결과 Event 순서
Zacks Event Segmentation: 독자의 뇌는 원인 Event → 결과 Event 순서로 처리. C-E Reversal 오답은 이 Event 순서를 뒤집어 인지적 자연스러움을 교란해. 화살표 방향 명시화로 극복.
소거 동작 (Action)
지문 인과 방향을 화살표로 표시: A → B.
선지를 같은 방식으로 변환 후 비교. 화살표 방향이 뒤집혔으면 소거.
P-S 혼동 주의: 빈칸이 원인(Cause) 자리인데 선지가 해결책(Solution)이면 C-E Reversal 변형.
실전 예시
22번 요지 — C-E Reversal
지문: 감정(원인) → 인간관계 판단 왜곡(결과)
오답: "인간관계가 우리의 감정에 영향을 미친다" — 인간관계(결과) → 감정(원인). Swap.
→ 화살표: 지문 = 감정→판단왜곡 / 선지 = 인간관계→감정 → 방향 Swap → 소거.
34번 빈칸 — P-S 위치 혼동 C-E Reversal 변형
지문 구조: "One reason we've failed [빈칸 = 원인 믿음]"
오답: "careful planning can fix the problem" — 해결책(Solution)이지 원인(Cause)이 아님.
→ 빈칸 자리 = Cause. 선지 = Solution. 논리 구조 위치 Swap → 소거.
⚠
Antonym vs C-E Reversal: Antonym = "A → 좋은 결과"를 "A → 나쁜 결과"로(극성 반대). C-E Reversal = "A → B"를 "B → A"로(주체·목적어 교환).
Group 3 — 위치 문제 유형 (⑥⑦)
6
True-but-Irrelevant 참이지만 무관형
지문에서 사실로 확인되지만 핵심이 아닌 선지
지문에 있고, 방향도 맞고, 실제로 한 말이지만 — 필자의 핵심 주장이 아닌 선지. 주로 Slot A 내용을 선지화.
이론: Hyland Slot A/B 구분 · Appraisal Attribute vs Proclaim · Halliday 일관성(Coherence) · Labov 평가 구간
Appraisal Theory 정밀 적용 — Attribute vs Proclaim
Attribute(속성 부여·타인 인용) 구간 = Slot A = TBI 지역
"According to X / It has been argued / Many believe / Traditionally"

Proclaim(선언·확신) + Engagement 수축 구간 = Slot B = 정답 위치
"Clearly / It is now evident / must / we should / What this means is"

TBI 오답 = Attribute 구간의 내용을 Proclaim처럼 포장한 선지.
소거 동작 (Action)
선지 내용이 지문 어느 위치에 있는지 확인. Attribute(Slot A) 내용이면 소거.
요지·주장 문제: 반드시 Proclaim(Slot B, However/Therefore/must 이후) 내용과 대응해야 정답.
실전 예시
22번 요지 — TBI (Slot A 내용)
지문 Slot A (Attribute): "감정은 주목할 만하고 중요한 정보를 준다."
만약 선지: "감정은 우리에게 중요한 정보를 제공한다" → 지문에 있음 + 방향 맞음 → 그러나 Slot A = TBI.
Slot B (Proclaim): "feelings can mislead you … not supported by facts" = 정답 위치.
→ Appraisal 확인: 선지 내용이 Attribute(Slot A)? Yes → TBI → 소거.
필자 주장 — TBI 가장 정교한 함정
지문: "Many economists assume markets are self-correcting [Attribute/Slot A]. Yet behavioral research reveals systematic biases [Disclaim]. It is now clear that cognitive biases distort market behavior [Proclaim/Slot B]."
TBI 오답: "Markets tend to correct themselves over time" — Slot A 내용 그대로.
→ "Many economists assume" = Attribute = Slot A → TBI → 소거.
⚠
가장 정교한 함정. 1단계(소재)·2단계(방향) 검증을 통과함. 오직 3단계(위치·Appraisal)에서만 걸림. 요지·주제·주장 문제에서 반드시 Attribute vs Proclaim 구분.
7
Misattribution 주체 혼동형
행위 주체(누가) 또는 행위 대상(누구에게)을 바꾼 선지
지문: "A가 B를 한다" / 선지: "B가 A를 한다". 소재·행위는 맞지만 행위자가 다름.
이론: Grosz 센터링 이론 (Center의 주체) · Mitkov 대형어 해소 메커니즘 · Construction Grammar 주어 자리
소거 동작 (Action)
지문에서 "누가(주어) 무엇을(동사) 누구에게(목적어)" 구조 확인.
선지의 주어·목적어가 지문과 일치하는지 대조. 뒤바뀌었으면 소거.
Grosz Center 체크: 지문의 담화 Center(주체)가 선지에서도 주어 자리에 있는가?
실전 예시
순서 배열 — Misattribution 변형 (대명사 오귀속)
지문: 과학자(A)가 이론을 제시 → 동료(B)가 검증.
오답 단락 조합: "They(= B 동료) proposed the theory" → 주체가 A→B로 swap.
→ 대명사 "they"의 선행사를 Mitkov 알고리즘으로 확인 → 잘못된 주체 귀속 → 소거.
출현 빈도: 지칭 추론(43~45번)에서 가장 명확. 대의파악·빈칸에서도 여러 주체가 등장하는 실험 지문에서 주의.

Framing Effect 프레임 전환형 · 신규
이중부정·반의어 치환으로 명제 방향을 뒤집은 선지
소재·방향·위치가 모두 맞아 보이지만, 이중부정이나 반의어 치환으로 명제의 최종 참/거짓이 뒤집힌 선지. 4단계 소거에서만 잡힘. 가장 정밀한 함정.
이론: Kahneman Framing Effect · Chomsky 심층 구조 vs 표층 구조 · Goldberg Construction Grammar (구문 의미 변화)
Framing Effect 3가지 패턴
패턴 A — 이중부정 프레임:
지문: "A must increase" → 선지: "A must not decrease" (의미 같아 보이지만 강도·범위 다를 수 있음)
지문: "A reduces B" → 선지: "A does not fail to reduce B" (이중부정으로 혼란)

패턴 B — 반의어 치환 프레임:
지문: "X is cognitively flexible(긍정)" → 선지: "X is not cognitively rigid(이중부정)" → 언뜻 같아 보이지만 강도 다름
지문: "reduces anxiety" → 선지: "does not increase anxiety" → 방향은 같아 보이지만 프레임 다름

패턴 C — 긍정↔부정 프레임 교체:
지문: Slot B = "we should embrace uncertainty" → 선지: "we should not cling to certainty" → 심층 구조는 같지만 표층 프레임 교체 → 처리 난이도↑, 혼란 유발
소거 동작 (Action)
이중부정 펴기: "not unable" = "able", "not decrease" ≠ "increase" (경우에 따라 다름).
명제 최종 방향 비교: 선지 전체를 긍정 명제로 전환 후 지문의 심층 구조와 비교.
Chomsky 심층 구조 검증: 표층(단어·구문)의 유혹에 속지 말고 의미 뼈대만 비교.
실전 예시
빈칸 추론 — Framing Effect 함정
지문 핵심: "rational decision-making requires evaluating future costs independently of past investments"
오답: "a failure to discount past costs does not support rational decision-making" — 의미 비슷해 보이지만 "failure to discount"의 이중 프레임이 추가 처리 부담 유발. 정답의 단순 paraphrasing에 비해 복잡.
→ 이중부정 펴기: "failure to discount past costs" = "counting past costs" → 지문 방향과 같지만 정답의 paraphrasing보다 더 복잡한 프레임 = Framing Effect 함정 가능성.
필자 주장 — 반의어 치환 Framing
지문 Slot B: "We must treat relationships with the same intentionality we bring to professional goals."
오답: "We should not neglect our close relationships in favor of career advancement" — 의미는 맞지만 "not neglect" 이중부정 + "in favor of career" 추가 프레임으로 처리 부하↑.
→ 이중부정 펴기: "not neglect" = "attend to" → 지문과 방향 같음 BUT "in favor of career" 불필요 추가 → Scope 왜곡 가능 → Framing 주의.
이론 배경(Kahneman Framing): 동일한 정보도 긍정 프레임("살아남을 확률 90%")과 부정 프레임("사망 확률 10%")으로 제시 시 판단이 달라짐. 출제자는 이 원리를 활용해 심층 구조는 같지만 표층 프레임이 다른 선지로 혼란을 유발해. 최종 판단은 항상 심층 구조(의미 뼈대)로.
