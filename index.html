실전 4단계 소거 프로토콜
ELIMINATION PROTOCOL v2 — 42분 내 선지를 만날 때마다 이 순서로 실행
1
소재 검증 — "지문에 있는 이야기인가?"
선지의 핵심 명사가 지문에 등장하는지 확인. 없으면 즉시 소거. Recognition Bias 주의 — 지문 단어가 있어도 의미가 바뀌었으면 2단계로. Relevance Theory 적용: 선지가 지문 맥락에서 최소 처리 노력으로 최대 인지 효과를 내는지 확인.
① Intrusion② Subset③ Scope Creep
2
방향 검증 — "지문의 논지 방향(Slot B)과 같은가?"
소재가 맞아도 방향(극성)이 같은지 확인. Appraisal Engagement 적용: 지문의 Disclaim(However/But) + Proclaim(clearly/must) 이후 = Slot B. 선지가 Slot B 방향인지 대조.
④ Antonym⑤ C-E Reversal
3
위치 검증 — "지문의 핵심 자리(Nucleus/Slot B)에서 온 내용인가?"
소재·방향이 맞아도 Slot A(Attribute/통념 구간) 내용이면 오답. Appraisal Engagement: Attribute(According to / Many argue) 구간 = Slot A. Proclaim(clearly/must) 구간 = Slot B = 정답 위치.
⑥ True-but-Irrelevant⑦ Misattribution
4
프레임 검증 — "이중부정·프레임 전환이 없는가?" ★NEW
소재·방향·위치가 모두 맞아 보여도 이중부정·반의어 치환·긍정↔부정 프레임 전환으로 의미가 뒤집혔으면 소거. Framing Effect(Kahneman): "not A"를 "B(반의어)"로 재프레이밍. 최종 명제 방향(참/거짓)만 비교.
⑧ Framing Effect
42분 압박 상황에서: 4단계 전부 실행이 어려우면 ① 소재 → ② 방향 순서로만 해도 오답 80% 소거. ③④단계는 2개로 좁혀진 후 적용.
Group 1 — 소재 문제 유형 (①②③)
1
Intrusion 침입형
지문에 없는 소재·개념을 끌어온 선지
선지의 핵심 소재가 지문 어디에도 등장하지 않는 유형. 가장 흔하고 소거가 가장 빠름 (3초 이내).
이론: Van Dijk 거시구조 · Bernstein 내부 논리 (지문 외부 맥락 금지)
지문 내 신호 (Signal)
선지 소재가 지문에 없음. 종종 지문 주제와 인접한 연상 소재를 쓰는 함정이 동반됨.
예: 회의 지문→"평가회" / 기후 지문→"에너지 효율" / 기억 지문→"신경가소성 훈련법"
Bernstein 폐쇄계 원칙: 지문 외부의 배경지식이 선지로 침입한 것 = 항상 오답.
소거 동작 (Action)
선지를 읽으며 핵심 명사를 지문에서 찾는다. 없으면 즉시 소거 (42분 기준: 3초 이내).
실전 예시 (2022 고1 6월)
20번 필자 주장 · 오답 ①②③④ — Intrusion ×4
① "회의 결과를 공개" / ③ "정기적인 평가회" — "생산적"은 지문 단어지만 "평가회"는 없음. Recognition Bias 동반.
→ 핵심 명사(결과·평가회) 지문 검색 → 없음 → 3초 소거.
24번 제목 추론 · 오답 ④
"How Algorithms Decrease Human Creativity" — "creativity" 없음. "algorithms"는 지문 단어 → Recognition Bias 동반 Intrusion.
→ "creativity" 지문 검색 → 없음 → 소거.
2
Subset 협소형
지문의 예시 중 일부만 커버 — 범위가 너무 좁음
지문에 있는 내용이지만 전체가 아닌 예시 하나에만 해당. RST 관점: 선지가 Nucleus가 아닌 Satellite(예시) 내용.
이론: Van Dijk 거시규칙 일반화 단계 실패 · RST Satellite → Nucleus 혼동
소거 동작 (Action)
지붕 테스트: "이 선지가 지문의 다른 예시들도 포괄하는가?" — 포괄 못하면 소거.
실전 예시
24번 제목 · 오답 ③⑤
③ "Dangers of Online Banking Algorithms" — bank 예시 하나. 비행·공장 포괄 불가.
⑤ "Transportation: A Driving Force" — flights 하나.
→ 지붕 테스트: 나머지 예시 포괄 불가 → 소거.
3
Scope Creep 과잉 일반화형
지문보다 범위가 지나치게 넓은 선지 — Subset의 반대
지문 내용을 과도하게 넓은 상위 개념으로 일반화. 특히 "always/never/all" 극단어, 헤징 언어 제거 패턴이 신호.
이론: Van Dijk 거시규칙 과잉 적용 · 학술 헤징 전략 위반
지문 내 신호 (Signal)
헤징 언어 제거 패턴: 지문 "tend to reduce" → 선지 "always reduces". 지문의 Hedge가 선지에서 사라짐 = Scope Creep 신호.
극단어 체크: always / never / all / only / completely
소거 동작 (Action)
"지문이 이 넓은 주장을 직접 했는가?" — No이면 소거.
실전 예시
23번 주제 · 오답 ④
지문: 아이들의 자발적 수학 개념 형성.
"importance of early childhood education" — 유아교육 전반으로 비약.
→ "지문이 교육 시스템 중요성을 직접 주장했나?" → No → 소거.
⚠
Subset vs Scope Creep: Subset → "다른 예시도 포괄?" / Scope Creep → "지문이 이 넓은 주장을 직접 했나?"
Group 2 — 방향 문제 유형 (④⑤)
4
Antonym 역방향형
지문의 논지·방향·극성과 정반대인 선지
소재는 맞지만 지문 논지 방향과 정반대. Recognition Bias와 결합 시 가장 위험.
이론: Kintsch Slot A/B · Appraisal Theory Disclaim/Proclaim · Bakhtin 다성성 (통념 목소리 ≠ 필자 목소리)
Appraisal Theory 적용 — 통념 vs 필자 목소리 분리
Attribute vs Proclaim 구분
Attribute = Slot A"According to X / Many argue / Traditionally" 구간 = 오답 지역
Proclaim = Slot B ★"However/Yet + Clearly/must/in fact" 구간 = 정답 방향
Antonym 오답 = Attribute 구간(통념·Slot A)을 필자 주장처럼 포장한 선지.
실전 예시
21번 함축 의미 · 오답 ①
지문: 잔 내려놓기 = 스트레스 해소(Slot B).
"pour more water" = 스트레스 추가. Blending Theory: down(해소) vs more(악화) → 방향 반대.
→ 은유 매핑 → 방향 반대 → 소거.
32번 빈칸 · 오답 ① ★핵심 이중 함정
"order more meat" — "meat"는 지문 단어(Recognition Bias)지만 가격↓ 시나리오 내용. 빈칸은 가격↑ 시나리오 = Antonym.
→ Recognition Bias 발동 → 그러나 반대 조건의 내용 → 소거.
5
Cause-Effect Reversal 인과 역전형
원인과 결과의 자리를 바꾼 선지 — Antonym과 구별
지문: "A → B" / 선지: "B → A". Event Segmentation: 독자의 뇌는 원인→결과 순으로 처리 — C-E Reversal은 이 순서를 교란.
이론: Halliday·Hoey 인과 결속성 · Zacks Event Segmentation · Kintsch 명제 극성
소거 동작 (Action)
지문 인과 방향을 화살표로 표시: A → B. 선지를 변환 후 비교. 방향 뒤집혔으면 소거.
P-S 혼동 주의: 빈칸이 원인(Cause) 자리인데 선지가 해결책(Solution)이면 C-E Reversal 변형.
실전 예시
22번 요지 · 오답 ③
지문: 감정(원인) → 인간관계 판단 왜곡(결과)
"인간관계가 우리의 감정에 영향" — Swap. (≠ Antonym: 방향이 아닌 주어·목적어 교환)
→ 화살표: 감정→판단왜곡 / 선지: 인간관계→감정 → Swap → 소거.
34번 빈칸 · 오답 ④
빈칸 자리 = 원인(Cause). "careful planning can fix" = Solution. P-S 구조 위치 혼동.
→ Cause 자리에 Solution 삽입 = 구조 Swap → 소거.
⚠
Antonym vs C-E Reversal: Antonym = "A→좋은결과"를 "A→나쁜결과"로(극성 반대). C-E Reversal = "A→B"를 "B→A"로(주체·목적어 교환).
Group 3 — 위치 문제 유형 (⑥⑦)
6
True-but-Irrelevant 참이지만 무관형
지문에서 사실이지만 필자의 핵심 주장이 아닌 선지
지문에 있고, 방향도 맞지만 — 핵심이 아닌 선지. 주로 Slot A(Attribute 구간) 내용을 선지화. 1·2단계를 통과하고 3단계에서만 걸림.
이론: Hyland Slot A/B · Appraisal Attribute vs Proclaim · Labov 평가 구간
Appraisal Theory 정밀 적용
Attribute vs Proclaim
Attribute = TBI 지역"According to X / Many believe / Traditionally" — 선지화 시 TBI
Proclaim = 정답 위치"Clearly / It is now evident / must / we should / What this means is"
실전 예시
22번 요지 — TBI 구조
Slot A(Attribute): "감정은 중요한 정보를 준다" — 지문에 있음 + 방향 맞음 → 그러나 Slot A = TBI.
Slot B(Proclaim): "feelings can mislead you … not supported by facts" = 정답 위치.
→ 선지 내용이 Attribute(Slot A)? Yes → TBI → 소거.
⚠
가장 정교한 함정. 1단계(소재)·2단계(방향) 통과. 오직 3단계(Appraisal 위치 확인)에서만 걸림. 요지·주제·주장 문제에서 반드시 Attribute vs Proclaim 구분.
7
Misattribution 주체 혼동형
행위 주체(누가) 또는 행위 대상(누구에게)을 바꾼 선지
지문: "A가 B를 한다" / 선지: "B가 A를 한다". 소재·행위는 맞지만 행위자가 다름.
이론: Grosz 센터링 이론 · Mitkov 대형어 해소 · Construction Grammar 주어 자리
소거 동작 (Action)
지문에서 "누가(주어) 무엇을(동사) 누구에게(목적어)" 구조 확인. 선지에서 뒤바뀌었으면 소거.
Grosz Center 체크: 지문의 담화 Center(주체)가 선지에서도 주어 자리에 있는가?
실전 예시 (2022 고1 6월)
23번 주제 — Misattribution 잠재 구조
지문: 아이들이(주어) 수학 개념을 탐구. 만약 선지: "교사가 아이들에게 수학을 가르치는 방법" → 주체 swap.
→ 지문 주어(아이들) vs 선지 주어(교사) → 불일치 → 소거.
Group 4 — 프레임 문제 유형 (⑧) · NEW
8
Framing Effect 프레임 전환형 · 신규★NEW
이중부정·반의어 치환으로 명제 방향을 뒤집은 선지
소재·방향·위치가 모두 맞아 보이지만, 이중부정이나 반의어 치환으로 명제의 최종 참/거짓이 뒤집힌 선지. 4단계 소거에서만 잡히는 가장 정밀한 함정.
이론: Kahneman Framing Effect · Chomsky 심층 구조 vs 표층 구조 · Goldberg Construction Grammar (구문 의미 변화)
Framing Effect 3가지 패턴
패턴 A — 이중부정 프레임:
지문: "A must increase" → 선지: "A must not decrease"
(의미 같아 보이지만 강도·범위 다를 수 있음)
지문: "A reduces B" → 선지: "A does not fail to reduce B"
(이중부정으로 혼란)
패턴 B — 반의어 치환 프레임:
지문: "X is cognitively flexible(긍정)" → 선지: "X is not cognitively rigid(이중부정)"
(언뜻 같아 보이지만 강도 다름)
지문: "reduces anxiety" → 선지: "does not increase anxiety"
(방향은 같아 보이지만 프레임 다름)
패턴 C — 긍정↔부정 프레임 교체:
지문 Slot B: "we should embrace uncertainty"
→ 선지: "we should not cling to certainty"
(심층 구조는 같지만 표층 프레임 교체 → 처리 난이도↑, 혼란 유발)
소거 동작 (Action)
이중부정 펴기: "not unable" = "able" / "not decrease" ≠ "increase" (경우에 따라 다름).
명제 최종 방향 비교: 선지 전체를 긍정 명제로 전환 후 지문의 심층 구조와 비교.
Chomsky 심층 구조 검증: 표층(단어·구문)의 유혹에 속지 말고 의미 뼈대만 비교.
실전 예시
빈칸 추론 — Framing Effect 함정
지문 핵심: "rational decision-making requires evaluating future costs independently of past investments"
오답: "a failure to discount past costs does not support rational decision-making" — 의미 비슷해 보이지만 "failure to discount"의 이중 프레임이 추가 처리 부담 유발. 정답의 단순 paraphrasing에 비해 복잡.

→ 이중부정 펴기: "failure to discount past costs" = "counting past costs" → 지문 방향과 같지만 정답의 paraphrasing보다 더 복잡한 프레임 = Framing Effect 함정 가능성.
필자 주장 — 반의어 치환 Framing
지문 Slot B: "We must treat relationships with the same intentionality we bring to professional goals."
오답: "We should not neglect our close relationships in favor of career advancement" — 의미는 맞지만 "not neglect" 이중부정 + "in favor of career" 추가 프레임으로 처리 부하↑.

→ 이중부정 펴기: "not neglect" = "attend to" → 지문과 방향 같음 BUT "in favor of career" 불필요 추가 → Scope 왜곡 가능 → Framing 주의.
이론 배경 — Kahneman Framing Effect
동일한 정보도 긍정 프레임("살아남을 확률 90%")과 부정 프레임("사망 확률 10%")으로 제시 시 판단이 달라짐. 출제자는 이 원리를 활용해 심층 구조는 같지만 표층 프레임이 다른 선지로 혼란을 유발해. 최종 판단은 항상 심층 구조(의미 뼈대)로.
특수 메커니즘 — Recognition Bias · 킬러 Construction
RB
Recognition Bias 재인 인지 편향 — 독립 메커니즘
지문 단어 재활용으로 친숙함=정답 착각 유도
Recognition Bias는 독립 유형이 아니라 ①~⑧ 어디에나 결합되는 출제자의 설계 기법이야. 지문 핵심 단어를 선지에 그대로 재활용해 친숙함(familiarity)을 유발한 뒤, 소재·방향·위치·프레임 중 하나를 교묘히 뒤틀어. 지문 단어가 많을수록 오히려 더 의심해야 하는 역원칙이 여기서 나와.
이론: Tversky & Kahneman 가용성 휴리스틱 · 처리 유창성(Processing Fluency)
오답 설계 공식 vs 정답 설계 공식
오답 설계 공식
지문 핵심 단어 3개+ 재활용
+ 인과 역전 / 주체 전환 / 프레임 교체
= Recognition Bias 오답
정답 설계 공식
지문 단어 거의 없음
+ 철저한 paraphrasing (동의어·상위어)
= 심층 구조 100% 일치 = 정답

실전 예시 (2022 고1 6월)
RB + Antonym — 32번 빈칸 ① ★★★
"order more meat" — "meat"는 지문에 있는 단어(친숙함↑)지만 가격↓ 시나리오의 것. 빈칸은 가격↑ 시나리오 = 조건 반전. RB + Antonym 이중 함정.
RB + C-E Reversal — 33번 빈칸 ②④ ★★★
② "free from social interaction" — "social interaction"은 지문 핵심 단어(친숙함↑)지만 방향 반전(없는 것이 정답이 아님).
④ "depending on genetic superiority" — "genetic superiority"는 지문 단어(친숙함↑)지만 실험에서 패배한 쪽 = C-E Reversal + Antonym.
RB + Intrusion — 24번 제목 ④
"How Algorithms Decrease Human Creativity" — "algorithms" 재활용(친숙함↑) + "creativity" 없는 개념 추가.

킬러 Construction 복합 함정
여러 오답 유형을 동시에 결합한 고난도 선지 설계
1등급 변별 문항(34번 빈칸·37번 순서)에서 주로 나타남. Recognition Bias가 기폭제 역할을 하면서 Antonym + C-E Reversal이 동시에 적용되는 복합 구조.
이론: Cognitive Load Theory (이중 처리 부담) · Chomsky 표층 구조 기만
킬러 Construction 대표 패턴
패턴 1 — RB + Antonym: 지문 핵심 단어 재활용 + 반대 방향 (32번 ①, 33번 ②④)
패턴 2 — RB + Scope Creep + Framing: 지문 예시 단어 + 과잉 일반화 + 이중부정
패턴 3 — C-E Reversal + Framing: 인과 역전 + 이중부정 프레임 동시 적용

소거 원칙: 킬러 Construction은 4단계를 순서대로 차근차근 실행해야 잡힘. 느낌으로 소거 금지. 반드시 화살표 방향 확인 + 이중부정 펴기 실행.
